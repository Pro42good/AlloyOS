## Required subsystem tests

- Disk/slot independence: real GPT partitions, active root ro, inactive root
  mountable, recovery independent, slot replacement leaves the other slot and
  STATE unchanged (hash checks in acceptance).
- Metadata: persistence across boots, dual-copy fallback, unknown/malformed
  field rejection, per-slot corruption isolation, fail-safe boot-record.
- Selection: GOOD A, PENDING B priority, GOOD B after mark-good, attempt
  decrements, three-attempt fallback, BAD no retry, A boots with B unbootable.
- mark-good: pending stays pending without confirmation, wrong-slot refusal,
  failed health refusal, accounting reset.
- Update: A→B and B→A inactive-only writes, active device hash unchanged,
  failed write/verification/power loss leave selection intact, hash mismatch
  hard failure.
- Manifest: valid signature accepted; modified payload/manifest, wrong key,
  wrong arch/profile/hardware, unsupported version rejected.
- STATE: user/settings survival, rollback survival, ephemeral clear on reboot,
  slot recreation does not delete STATE, OS reset vs STATE wipe distinction.
- Schema: N→N+1 additive migration, rollback, failed migration aborts
  activation, irreversible migration rejected.
- Recovery: boots with A broken, B broken or both; reinstall one slot; change
  active/fallback; preserve STATE; explicit full reset.
- Profiles: prod rejects lab/dev; dev override impossible in prod; arch and
  hardware mismatch rejected.
- QEMU integration: all 14 required scenarios above exercised.
